JuanDeColonia_SocialClub

## Descripción
Este proyecto se trata de una red social solamente para alumnos dentro del la junta de EducaCyl, en el que aquellos que tengan una cuenta creada podran ver post de otros alumnos, o subirlos ellos mismo

## Tecnologías previstas
- Frontend: TailwindCSS, Toast, Next.js
- Backend: Next.Js, Firebase
- BBDD: Firestore(Bases de datos no relacionales de Firebase)
